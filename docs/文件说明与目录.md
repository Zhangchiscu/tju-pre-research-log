# 仓库文件说明与目录

仓库里有一些英文文件名，主要是程序、日志和自动生成的结果。为了不影响已有代码和恢复记录，保留了这些文件名；可以直接通过下面的中文说明找到对应资料。

**查阅顺序**：只想看本次做了什么，可以先读“科研工作记录”；想看视频和运行过程，打开“仿真运行记录”；想了解任务得分的判定方式，读“叠碗任务配置与评价说明”；要重新配置服务器，再看“云服务器环境恢复说明”。

## 文件名里常见的英文

- `daily`：工作记录；`docs`：说明文档；`evidence`：测试资料与原始结果；`scripts`：执行脚本。目录名保留英文，避免改变现有路径。
- `real_simulation`：真实物理仿真的运行记录（区别于离线接口测试）；`restore_manifest`：恢复环境时参考的软件和源码清单。
- `.md`：可以直接在 GitHub 阅读的 Markdown 文档；`.py`：Python 代码；`.ps1`：PowerShell 脚本；`.log`：终端日志；`.txt`：纯文本。
- `.json`：结构化数据；`.mp4`：视频；`.patch`：源码修改差异；`pip_freeze` / `conda`：Python 软件包或 Conda 环境清单。

## 关于备份

云服务器上的三个大型压缩包（RoboDojo Assets、XPolicyLab 与 CuRobo、Isaac Lab 源码）此前已在 Windows 本地下载并通过 SHA-256 校验，但**不在这个 GitHub 仓库里**。具体压缩包名称和恢复位置见 [云服务器环境恢复说明](云服务器环境恢复说明.md)。

仓库中的日志、检查摘要与最终运行结果对应不同阶段，有些旧记录写着当时还没有完成仿真，不表示后来没有运行。最终实验结果请以第 8 次运行日志、三路视频和 `_result.json` 为准。
