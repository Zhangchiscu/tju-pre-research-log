## 文件名中的英文

`daily` 是工作记录，`docs` 是说明文档，`evidence` 是原始结果，`scripts` 是脚本；`.log` 是终端日志，`.json` 是结构化数据，`.mp4` 是视频，`.patch` 是源码修改补丁。

早期排障日志和重复检查输出已从当前 `evidence` 中精简，但仍可通过 Git 历史提交恢复；最终运行结果和环境复现所需的主要记录均保留。
